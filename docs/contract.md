# 多视图点重建 v1

教学数据处理输入2..20个唯一相机id和已给3×4投影矩阵P（行秩3），1..200条唯一track，各2..20个不同相机的xy观测和正weight。所有输入数值为有界十进制字符串，Fraction精确计算；不读取照片，不自动匹配特征或标定相机。

设齐次世界点[X,Y,Z,1]，观测x/y建立线性行(x×P3-P1)·XYZ=P14-x×P34及对应y行。每观测两行同权，求加权代数残差平方和最小解。满秩才返回唯一XYZ，秩亏为unobservable且xyz=null，不任意固定深度。该算法最小化代数残差，不是非线性像素重投影最优；投影矩阵行/整体缩放会改变代数权重，调用方需统一矩阵尺度与权重约定。

重建点按原P回投影，depth=P3·[XYZ,1]；depth=0时xy/残差null，非正深度明确标诊断而不删除点。positive_depth仅相对于给定矩阵符号，不推断真实相机朝向。输出逐观测残差、加权代数误差和严格为0的正规方程残差。样例平移基线相机恢复XYZ=[2,1,4]，回投影残差均0。

没有畸变、噪声统计认证、全局束调整、坐标系自动识别或地理网格节点生成。观测不可辨识/非正深度属于业务报告退出0；输入错误退出2。全部结果计算完后原子新建JSON，拒绝已有目标文件和符号链接。
